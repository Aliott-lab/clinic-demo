# Sepehr Aramesh: demo

Static demo of the Sepehr Aramesh booking system: the admin panel, the secretary panel, the counselor panel and the client portal.
Each panel is the real app, built from the current code, running in the browser on made-up data. There is no server and nothing is sent anywhere; a reload starts over.
Every panel opens signed in. After signing out, any username and password logs in (any 09… number and any code for the counselor panel).

This repository holds only the built demo files, not the application source.
