# Sepehr Aramesh: demo

Static demo of the Sepehr Aramesh booking system: the client portal, the front-desk panel and the counselor panel.
Everything runs in the browser on made-up data. There is no server and nothing is sent anywhere.
Any username and password logs in (any 09… number and any 5-digit code for the counselor panel).

This repository holds only the built demo files, not the application source.
